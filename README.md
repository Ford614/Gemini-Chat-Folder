# Gemini Folder Helper

Geminiのサイドバーにフォルダ機能を追加するChrome拡張機能です。
増えすぎたチャット履歴をドラッグ＆ドロップでフォルダ分けして整理できます。

## 使い方

1. `+ フォルダ` ボタンでフォルダを作成
2. 「最近」の会話をドラッグ＆ドロップでフォルダに格納
3. フォルダ名をクリックで開閉（畳む）
4. チャット横の `✕` でフォルダから解除（元の「最近」に戻ります）

※フォルダに入れた会話は、元の「最近」一覧から自動で隠れる仕様です。

## インストール手順

ストア非公式の自作拡張機能のため、以下の手順で手動追加します。

1. このリポジトリのコードをダウンロード（ZIP解凍）します。もしくは、ReleaseページからSourse Code.Zipをダウンロード。
2. 解凍したフォルダ内に `manifest.json` と `content.js` があることを確認します。
3. Chromeのアドレスバーに `chrome://extensions/` を入力して開きます。
4. 画面右上の **「デベロッパー モード」** をONにします。
5. 左上の **「パッケージ化されていない拡張機能を読み込む」** を押し、解凍したフォルダを選択します。
6. [Gemini](https://gemini.google.com/) を開き、ページを更新（F5）するとサイドバーに表示されます。
